## Intent

HTML in Thoxa is a **tag expression** that builds a builtin **`Node`** tree.
`n.html()` is escaped markup. No import — same ambient shape as `String` /
`Array`. Components are **types that produce `Node`**, not subtypes of `Node`.

```thx
type Card(title: String) {
    export fn view(children: Array<Node>) -> Node {
        <section class="card">
            <h1>{title}</h1>
            {children}
        </section>
    }
}

let n = <Card title="Hi"><p>Hello, {name}</p></Card>
logging.info(n.html())
```

## Locks (v0)

### 1. Value

- Builtin `Node` (`Ty::Node` → `ThoxaHtml*` in `thoxa_rt`).
- Matchable as `Element | Text | Fragment` (same tree, not a second sum).
- Ambient ctors (no import): `Element(tag, attrs, kids)`, `Text(s)`,
  `Fragment(kids)`, `Attr(name, value)`. Calls follow D200 (**D203**,
  2026-10-18): `Element(tag:, attrs:, kids:)` and `Attr(name:, value:)` are
  labelled, `Text("…")` and `Fragment([…])` positional (was `Text(s: …)`,
  `Fragment(kids: …)`).
- Legal constructor-param field (**D135**). Recursive `Node` fields are an
  error; `Array<Node>` / `Map<…, Node>` is fine.
- RC like other heap values. Not a Map key.

### 2. Tag vs comparison

- `<name` / `<>` with **no space** after `<` is a tag, including after another
  expression.
- Comparison is `a < b` (space after `<`).
- Glued `a<b` / `n<3` is an **error** (help: spaces to compare, or `<tag` on
  its own).

### 3. HTML tags

`<div class="x">…</div>` / `<br />` desugar to internal `__jsx_el` (not a
user-facing `el`). Children wrap through `__jsx_child`; attr `{e}` through
`__jsx_attr`. Do not steal names `el` / `child` / `html`.

### 4. Components

PascalCase `<Card title="Hi">…</Card>` is **eager**
`Card(title: "Hi").view(children: […])`. The type must have
`fn view(children: Array<Node>) -> Node` (usual method rules). Components
are not `Node` and do not inherit.

### 5. Fragments

`<>…</>` is a fragment `Node`. Empty `<>` is a valid `Node` (empty fragment).

### 6. `{e}` children

| Type | Meaning |
|------|---------|
| `String` | escaped text node (`&` `<` `>` at `thoxa_html_text`) |
| `Int64` / other ints / `Float64` / `Bool` | stringify (same table as interpolation), then text |
| `Node` | identity |
| `Array<Node>` | splice as a fragment |

Anything else is an error. `{for x in xs { child }}` collects `Array<Node>`
(statement `for` is unchanged). `{for}` is **child position only**.

### 7. Attributes

- Names: `class`, keywords (`type`, `for`), hyphenated (`data-*`, `aria-*`).
- Value: `"…"` or `{e}`. `{e}` is `String` / `Int64` / other ints / `Float64` /
  `Bool` (stringify).
- Bare `disabled` → empty value; `.html()` emits `disabled` (no `="…"`).
- HTML `{...xs}` is `Array<Attr>`. Later attrs **append** (no name-merge /
  last-wins rewrite). Duplicate names may both appear.
- Component `{...p}` copies ctor fields of a product `p`; later named props
  win (usual named-arg spread).

### 8. Raw text

Source slice between tags (lexer `Junk` so `'` / `·` survive). Whitespace-only
gaps drop. Bare `#` is a line comment. **`\#` is a literal `#`**.

### 9. `.html()`

`Node.html() -> String`. No arguments. Escaped markup, **no** pretty indent /
doctype. Void tags (no close): `br` `hr` `img` `input` `meta` `link`. Attr
values escape `&` and `"` at render. Text already stored escaped.

`std/http.htmlResponse` / `htmlFragment` wrap this; they are **D137** / **D145**,
not this freeze.

### 10. LSP

`Node`, `Element`, `Text`, `Fragment`, `Attr` are builtins (hover + outline).
Go-to-def on `.html` is out of v0 (MIR builtin, not a resolver member).

## Non-goals (punt)

| Item | Why |
|------|-----|
| `className`, hydration, client VDOM | SSR tree only |
| Components `is Node` / inheritance | Types produce Node via `view` |
| `Node` in `"{n}"` / generic `toString` / `repr` | Separate parked idea; keep `.html()` as the codec |
| Extra void tags (`area`, `wbr`, …) | Grow the list from a sample |
| Attr name-dedup / Map spreads | Append `Array<Attr>` is enough |
| `{for}` as an attribute | Child position only |
| User-facing `el` / `child` | Desugar names stay `__jsx_*` |
| Tree-sitter `<>` polish | Extras; compiler already parses fragments |
| Dedicated `.html()` hover | General builtin-method hover, not JSX-specific |
